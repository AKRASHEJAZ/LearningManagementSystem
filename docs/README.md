# Docs Index

These files are maintained so any agent or contributor can understand:
- what the project is,
- what will be built next,
- what is already implemented.

## Start Here

- `AGENTS.md` (repo root): rules of thumb and guardrails
- `docs/PRODUCT_WORKPLAN.md`: full end-to-end plan (product, DB, Laravel, UI/UX, security, deployment)
- `docs/IMPLEMENTATION_STATUS.md`: living checklist of progress and decisions
- `docs/VERIFY_IN_BROWSER.md`: required manual smoke tests after UI/flow changes

## Update Rules

When implementing features, keep `docs/IMPLEMENTATION_STATUS.md` updated and adjust the plan if reality changes.
